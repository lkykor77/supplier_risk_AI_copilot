01

The problem

Keyword matching can accept a denied security practice and miss an equivalent statement. The analyst needs a reason, a quote, and a way to correct the conclusion.

02

The boundary

Five fictional buyer requirements, four statuses, and one local analyst workflow. No compliance certification, automatic approvals, or supplier-facing portal.

03

The tradeoff

Local inference keeps supplier answers on the machine but is slower than the earlier cloud run. Explicit mapping adds review effort while avoiding guessed PDF relationships.

04

The failure & fix

Early local responses put JSON in the reasoning channel with empty final output. The parser rejected them. Explicit reasoning configuration produced usable final JSON.
