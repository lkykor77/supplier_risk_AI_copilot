# Portable sample Obsidian vault

Open this folder as a vault in Obsidian, or use its Markdown notes through the application's existing allowlist loader. It contains public assessment guidance and project memory only. No private vault content is copied here.

The curated three-question showcase run reads `assessment-rules.md` as rules and `project-memory.md` as memory. Both are context for the local model, never supplier evidence. This demonstration reads existing memory; it does not claim to have automatically written a new memory note.
