    ENGINEERING DETAILS

    From documents to decisions.

    A bounded Python AI harness connects retrieval, local inference, exact citations and human review.

    1. ExtractPDF text and on-device OCR
    2. RetrieveSupplier-scoped BM25 + local embeddings
    3. GuideSelected Obsidian rules & memory
    4. GenerateOpen Weight LLM via LM Studio
    5. Validate & reviewSource citations, corrections and risk score

    Evidence stays separate.

    Private SQLite indexes are isolated by supplier. Document hashes, page numbers and immutable run snapshots preserve provenance. Obsidian context is not added to the supplier index.

    The human owns the decision.

    Exact quote checks reject fabricated citations. They cannot establish that a conclusion is correct. A final questionnaire risk indicator requires every explicit human decision.

    Validation and limitations

    64 automated tests cover isolation, evidence checks, local transport and review persistence. Both keyword and hybrid retrieval found all seven draft expected page references across six queries over a three-page development fixture; that does not establish real-world accuracy or hybrid superiority. Korean retrieval quality is not yet validated.

    The showcase uses public sample Obsidian notes. Your personal vault remains separate and is loaded only when explicitly selected in the analyst workspace. The showcase reads memory; it does not automatically write a new memory note.
